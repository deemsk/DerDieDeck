# Compact English dictionary review actions

## Why
The companion-card explanation and long inline action prompt repeat information
and make the terminal review difficult to scan.

## What Changes
Separate the pending cards from an aligned action menu and a short input prompt.
Use English interface labels, dim headings, and emphasized shortcut keys. Apply
the same structure to ready and failed dictionary reviews, including standalone
cards. Use one column when two columns would not fit. Preserve existing shortcuts,
Enter behavior, generation, and note creation semantics. Card content remains in
its existing learner languages. No existing notes are changed.

The user approved the compact menu shown in chat, with English interface text.
