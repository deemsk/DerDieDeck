# Generate image searches from the chosen meaning

After the learner selects a meaning, prepare one concrete image-search query using the selected sense and verified example. A model-provided visual scene takes precedence over generic classification templates. Do not turn a group of students into a sign for an institution. If generation fails, retain the normal search workflow without presenting a fabricated template as a verified scene.

Use the same contextual preparation for picture words, word sentences and picture verbs. The example provides optional context rather than requiring the image to reproduce its scene; prefer an image that makes the selected lexical meaning memorable. Make one model request after confirmation; do not run an additional model review or maintain per-word prompt examples. Retain a safe fallback if the request fails or returns an empty query.
