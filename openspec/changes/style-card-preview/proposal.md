# Distinguish card previews from word summaries

## Why
Learners need a consistent visual layout while distinguishing lexical information
from the complete card they are about to save.

## What Changes
Use the Word summary framing, indentation and muted aligned labels for the
form-card preview. Title it Card preview and color its frame green, retaining
the cyan target and existing action colors. Use English interface labels while
preserving Russian learning content, Front/Back sections and all available data.
This is terminal presentation only; saved cards and review actions are unchanged.

## Consistent coverage
All interactive pre-save previews SHALL use the same Card preview frame: picture
words, sentence words, picture and sentence verbs, optional infinitives, verb
packages, sentence card sets, single sentences, and grammar selections. Preserve
all existing fields, toggles, optional metadata and duplicate warnings. Summary
blocks remain informational and cyan. Review actions remain outside the frame.
Use a shared renderer to prevent presentation drift between workflows.
