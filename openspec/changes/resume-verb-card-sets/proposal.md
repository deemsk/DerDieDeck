# Resume interrupted verb card sets

## Why
A verb form, its example and a morphology package can be only partially saved, and the existing duplicate guard prevents completing them after interruption.

## What Changes
Save an approved verb-card plan before note writes, and reuse the word-card journal and reconciliation to resume only missing steps. Preserve exact fields, note types, decks, audio and cloze content. Never retry an uncertain write without reconciliation.
